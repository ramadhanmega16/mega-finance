MEGA FINANCE — DEMO WEBSITE

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder mega_finance.
3. Klik dua kali index.html atau buka melalui browser (Chrome, Edge, Firefox).
4. Pilih menu Transaksi > Tambah Transaksi untuk mulai mencatat.

Fitur:
- Dashboard saldo, pemasukan, pengeluaran.
- Tambah, edit, hapus, dan cari transaksi.
- Filter pemasukan/pengeluaran.
- Grafik bulanan dan kategori pengeluaran.
- Laporan ringkas.
- AI Assistant demo berbasis aturan lokal.

Penyimpanan:
Data disimpan di LocalStorage browser/perangkat yang digunakan. Data tidak otomatis tersinkron ke perangkat lain. Hapus data browser dapat menghapus data aplikasi.

Catatan AI:
AI Assistant pada versi ini adalah simulasi analisis berbasis aturan JavaScript lokal, bukan model AI eksternal. Untuk AI sungguhan diperlukan backend/server dan API AI; jangan menaruh API key rahasia di HTML/JavaScript frontend.

Catatan keamanan:
Ini prototipe pembelajaran, belum memiliki login, sinkronisasi cloud, enkripsi data finansial, atau audit keamanan. Jangan gunakan untuk menyimpan data keuangan sensitif/riil sebelum pengamanan dan backend diterapkan.
